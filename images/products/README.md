# Product photos

Put product photos in this folder. Each photo must use the **exact file name** listed below. Once the file is here, the website shows the photo automatically. Until then it shows the icon.

**Tips for good photos**
- Use your own photos from the shop: a phone camera, good daylight and a plain white or light background.
- Make them square (for example 600 × 600 px) and keep each file under about 150 KB. That keeps the site fast on mobile data.
- Use `.jpg` files. To use a different name or format, change the `img:` value for that product in `js/products.js`.
- Only use photos you took yourself or photos with a free licence. Do not copy photos from Amazon, BigBasket or brand websites.
